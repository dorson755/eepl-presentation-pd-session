# eepl-presentation-pd-session
Presentation for Professional Development Session, Monday 24th August 2026

## Structure

- `index.html`: gallery page for available presentations.
- `presentations/pd-session/index.html`: Reveal.js presentation for the PD session.

## Usage

Open `index.html` in a browser and choose a presentation.

If your browser blocks module/CDN resources when opened as a local file, run a simple static server from the repository root, for example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
